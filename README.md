# claude-things1

## Karinderya ni Lola

A phone-first browser game set in a Filipino karinderya. Cook Lola's recipes
through mini-games each morning, then plate orders and wash plates during the
lunch rush.

- Play: open `karinderya/index.html` in a browser (no build step).
- Design notes and roadmap: [`karinderya/DESIGN.md`](karinderya/DESIGN.md)
